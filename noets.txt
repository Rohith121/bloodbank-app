"Where does Metrics Server run?"

Answer:

Metrics Server is deployed as a Kubernetes Deployment, typically with one replica. It runs as a pod scheduled by Kubernetes, not as a service installed on every node. It collects CPU and memory usage from the kubelets on all nodes.

If they ask:

"Where does kube-state-metrics run?"

Answer:

kube-state-metrics is also deployed as a Deployment, usually with one replica. It watches the Kubernetes API and exposes metrics about Kubernetes objects such as Pods, Deployments, StatefulSets, DaemonSets, and Nodes. It does not collect CPU or memory usage.

Installation steps

helm repo add prometheus-community https://prometheus-community.github.io/helm-charts

helm repo add grafana https://grafana.github.io/helm-charts

helm repo update 


we can check in helm 
cmd   helm list -A

create the namespace for that  monitoring to isolation


helm install monitoring prometheus-community/kube-prometheus-stack \
-n monitoring \
--create-namespace

kubectl port-forward svc/monitoring-grafana 3000:80 -n monitoring

kubectl port-forward svc/monitoring-kube-prometheus-prometheus 9090:9090 -n monitoring
